Privacy Policy

Effective date: February 16, 2026

open-os LLM Browser Extension does not collect, transmit, store on external servers, or share any personal or sensitive user data.

1. Data Collection

This extension does not collect any personal information. The extension stores the following user preferences locally using Chrome Storage:

  • User-defined display name
  • LLM display name
  • Selected theme
  • Font size preferences
  • Pre-prompt configuration
  • Selected local identity (if any)

All stored data remains within the user's browser. If Chrome Sync is enabled on the user's browser, Chrome may synchronize these preferences across devices through Google's own infrastructure. This is a standard Chrome feature and is not controlled by the extension.

2. Network Communication

The extension communicates only with a locally running Ollama instance on the user's machine (typically http://localhost:11434). No external servers are contacted by the extension.

3. No Analytics or Tracking

This extension does not use analytics, tracking technologies, or telemetry. It does not sell or share user data.

4. Data Control

Users may delete all stored settings at any time by removing the extension or clearing Chrome extension storage.

5. Contact

For questions about this privacy policy, contact info@open-os.com.
