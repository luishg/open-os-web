01 — Why

Building a different relationship with technology — and paving the way toward intelligent operating systems.

open-os develops and promotes technologies that work across platforms, respect your data, and remain open for anyone.

    Works across platforms, providers and operating systems.

02 — Mission manifest

Five active missions.

M—01
In Progress Open Source

Open-OS Index

The Freedom Index for operating systems.

A public ranking that certifies how well each operating system respects user sovereignty, neutrality, and general-purpose computing. Every grade follows a public rubric, with cited evidence and full history.

Operating systems are scored across three weighted axes — owner sovereignty, ecosystem freedom, and technical openness — spanning nine dimensions and graded from S (Absolute Sovereignty) to F (Hostile).

index.open-os.com Rubric 2.0
M—02
Released Open Source

LLM Browser Extension

Browser interface for local language models.

A lightweight extension that connects to any LLM running on Ollama (Llama, Mistral, Phi, Gemma, and others). Chat with AI directly from your browser without external servers, accounts, or telemetry.

Available for Chromium browsers (Chrome, Brave, Edge).

Coming soon: Soul Protocol integration for persistent context across sessions.

GitHub Chrome Web Store
M—03
In Progress Open Source

open-os cli

A terminal emulator with a secure, built-in AI assistant — no accounts, no telemetry.

A lightweight terminal emulator with integrated AI assistance powered by local LLMs via Ollama. Ask questions directly in the terminal, get context-aware suggestions, and approve commands before execution — no external servers, no accounts, no telemetry.

Available as AppImage for any Linux distro and as a native package for Arch Linux.

GitHub Download for Linux / Mac / Windows
M—04
In Progress Open Source

Soul Protocol

Specification for portable AI identities.

An open specification for portable AI identity. A standardized system of interconnected Markdown files that define an AI assistant's identity, knowledge, preferences, and reasoning patterns — independent from any specific model or provider.

Change the brain. Keep the soul.

soul-protocol.com
